Every component in a model file has an `id`, a `type` from this page and the
parameters listed for that type. Quantities accept a unit string (`25 bar`,
`6 mm`, `0.5 lb/s`); bare numbers are SI, in the unit given in the SI column.
Parameters marked schedulable also accept a table `[[t, value], ...]`,
interpolated linearly in time. The equations behind each type are in the
engineering section; the output channels each type produces are listed in
[Output channels and result files](outputs.md). The model file format itself is
in the [model file standard](model-files.md).

## Boundaries

### boundary

**Pressure boundary.** Fixed (or scheduled) pressure and temperature. Supplies fluid at its own state; absorbs outflow at any state.

Ports: `p`. Network role: node (its port joins the node it is connected to).

| Key | Label | Unit | Default | Sched. | Description |
|---|---|---|---|---|---|
| `fluid` | Fluid | fluid key | required |  | Working fluid (propagates through connected flow elements). |
| `P` | Pressure | Pa (UI: bar) | required | yes | Boundary pressure (constant or [[t, P], ...]). |
| `T` | Temperature | K | – | yes | Boundary temperature for inflow into the network. |
| `x` | Quality | – | – | yes | Vapour quality for a saturated boundary, instead of T. |

### mass_flow

**Mass flow source.** Imposed mass flow from 'in' to 'out' (ideal pump / flow controller).

Ports: `in`, `out`. Network role: branch or standalone element.

|---|---|---|---|---|---|
| `mdot` | Mass flow | kg/s (UI: g/s) | required | yes | Imposed mass flow, constant or [[t, mdot], ...]. |

## Machines

### shaft

**Shaft.** Rotor with inertia. Pumps and turbines that name it share its speed; J dw/dt = sum of turbine torques - pump torques - losses.

Ports: none (not connected by ports). Network role: branch or standalone element.

| Key | Label | Unit | Default | Sched. | Description |
|---|---|---|---|---|---|
| `inertia` | Inertia | kg m2 | required |  | Polar moment of inertia of the rotating assembly. |
| `N0` | Initial speed | rad/s (UI: rpm) | 0 rpm |  | Speed at t = 0. |
| `bearing_torque` | Bearing torque | N m | 0 N m |  | Speed-independent friction torque (smoothed through zero speed). |
| `viscous_loss` | Viscous loss | N m s | 0 |  | Loss torque per unit speed. |
| `speed` | Fixed speed | rad/s (UI: rpm) | – | yes | Prescribe the speed (motor drive) instead of solving the torque balance. |
